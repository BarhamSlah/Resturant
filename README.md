# 🍽️ Restaurant Ordering System

A Java application simulating a digital ordering system for a restaurant menu. Originally designed as a terminal application and upgraded to an interactive GUI, this project lets users browse items, place orders, calculate totals, and view receipts.

---

## 📌 Features

- **Interactive GUI:** Built using Java's `JOptionPane` for clear visual pop-ups and user interactions.
- **Dynamic Cart & Bill Calculation:** Calculates subtotal, total price, and displays order items dynamically.
- **Menu Management:** Supports multiple menu options and selection handling.
- **Input Handling & Validation:** Handles order selections cleanly to ensure smooth user flow.

---

## 🛠️ Built With

- **Language:** Java (JDK 17 or higher recommended)
- **GUI Framework:** Java Swing (`javax.swing.JOptionPane`)
- **IDE:** IntelliJ IDEA
- **Version Control:** Git & GitHub
